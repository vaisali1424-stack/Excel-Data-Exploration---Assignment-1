# 📊 Excel Data Exploration – Product Dataset Analysis

This repository contains a complete data exploration project performed using Microsoft Excel.  
The dataset includes product information such as Product ID, Product Name, Brand, Category, Price, and Quantity.

This project demonstrates essential data analyst skills including:
- Data cleaning
- Data summarization
- Logical functions
- Conditional aggregation
- Text extraction
- Insight reporting

---

## 📁 Dataset Overview

The dataset contains the following columns:
- **Product ID** (e.g., 28-JAN-US)
- **Product Name**
- **Brand Name**
- **Price ($)**
- **Quantity**
- **Category**

Each Product ID encodes:
- **Day** → First 2 characters  
- **Month** → Characters 4–6  
- **Country Code** → Last 2 characters

## ✅ Tasks Completed

### 1. Basic Data Exploration
- **Total Price:**  
  `=SUM(D2:D35)`
- **Total Products:**  
  `=COUNTA(B2:B35)`
- **Average Price:**  
  `=ROUND(AVERAGE(D2:D35),0)`

### 2. Minimum & Maximum Price
- **Minimum Price:**  
  `=MINA(D2:D35)`
- **Maximum Price:**  
  `=MAXA(D2:D35)`

## 📈 Key Insights

- Electronics category has the **highest total price contribution**.
- High‑priced items (≥ $500) include laptops, smartphones, and tablets.
- Standard‑priced items (< $500) form the majority of the dataset.
- Several products fall under the **under $100** segment (e.g., Toaster, Jeans, Microwave).
- Text extraction from Product ID enables **date‑wise and country‑wise analysis**.
